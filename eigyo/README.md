# 営業リサーチ＆アプローチ ツール

ターゲット企業を調べ、課題の仮説を立て、**営業メール・DM・フォローアップ文面**（＋任意でその企業向けのサンプルLP）まで一気に生成する単一HTMLアプリ。NoCodeBootCamp 成果物。

- 公開URL: https://masato19870410.github.io/ncbc/eigyo/
- 構成: `index.html` 1ファイル（HTML+CSS+JS インライン、ビルド不要）
- データ: すべてブラウザの localStorage 保存（サーバーなし）

## 使い方

1. 右上「⚙ 設定」から **Anthropic API キー** を入力（[console.anthropic.com](https://console.anthropic.com/settings/keys) で発行）。
   - 任意で「自分の情報」（商材・強み・料金感・署名など）を入力すると文面の質が上がります。
2. **リサーチ**タブで
   - 「エリア×業種で探す」: エリアと業種を入れて候補企業を一覧取得（各社のサイト有無・品質を評価）
   - 「特定の1社を調べる」: 会社名 / URL を深掘り
3. **見込み客**タブで、狙う相手の「攻略」を押す → 調査メモ・課題仮説・メール・DM・フォローアップ・想定反論・サンプルLP を生成
4. 各文面は「コピー」、サンプルLPはプレビュー＋HTMLダウンロード

## 技術メモ

- Claude API（`claude-opus-5` / `claude-sonnet-5` を設定で選択）をブラウザから直接呼び出し
  （`anthropic-dangerous-direct-browser-access: true`）
- リサーチは `web_search` サーバーツールを使用。`pause_turn` を最大6回まで継続
- 応答は JSON 指定 → フェンス除去してパース、失敗時は生テキスト表示＋再実行
- 概算コストを usage から算出して表示
