# 営業リサーチ＆アプローチ

会社名やエリア×業種を入れると、AI（Claude）がその相手をネットで調べ、**課題の仮説・営業メール・DM・フォローアップ文面**、必要なら**その企業向けのサンプルLP**まで生成する単一HTMLツール。

**▶ ツールを開く: https://masato19870410.github.io/ncbc/eigyo/**

## できること

- **リサーチ** — 「世田谷区 × 美容室」のようなエリア×業種、または会社名／URL を入力。実在の事業者を集め、自社サイトの有無と品質（サイト無し／SNSのみ／古い／十分）を評価
- **課題の仮説** — 設定した自分の商材・強み・料金感を踏まえ、相手が抱えていそうな課題を言語化
- **アプローチ一式** — 件名つき営業メール、DM／問い合わせフォーム向けの短文、フォローアップ2通、想定反論と返し
- **サンプルLP生成** — Web制作など「見せられる」商材なら、その企業向けの1ファイルHTMLを生成。プレビュー＋ダウンロード
- 見込み客リストは表示・CSV出力・端末内保存。生成物も端末に残る

## 使い方

1. 右上「⚙ 設定」で **APIキー** を登録
   - [console.anthropic.com](https://console.anthropic.com/settings/keys) に登録（クレジットカード＋数ドルのチャージ）→「Create Key」で発行
   - `sk-ant-` で始まる文字列を貼り付け。鍵はこのブラウザにのみ保存され外部送信しません
2. 任意で「自分の情報」（商材・強み・料金感・署名など）を入力すると文面の質が上がります
3. 上のバーでリサーチ → 左のリストで相手を選ぶ → 「アプローチ一式を作る」

## 構成

- `index.html` 1ファイル（HTML・CSS・JS インライン、ビルド不要）
- ホスト: GitHub Pages
- Anthropic Messages API をブラウザから直接呼び出し（`anthropic-dangerous-direct-browser-access`）
- リサーチは `web_search` サーバーツールを使用。`pause_turn` を最大6回継続
- 応答は JSON 指定 → フェンス除去してパース、失敗時は生テキスト表示＋再実行
- 設定・APIキー・見込み客・成果物はすべて `localStorage` 保存

## 料金・注意

- AI 利用料は**自分の Anthropic アカウントに課金**されます（1リサーチ＋1文面作成でおおよそ数十円〜数百円、モデルと件数による）。右上に概算（円）を表示。
- 生成メールは**下書き**です。送信前に必ず内容を確認してください。
- **公開されている連絡先**のみを使い、各国の法令（日本：特定電子メール法／米：CAN-SPAM／EU：GDPR 等）を守り、無差別な大量送信は行わないでください。
- API キーはこの端末のブラウザにのみ保存されます。共有PCでは使用しないでください。
