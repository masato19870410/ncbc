# 営業リサーチ 2.5

岡山市内の事業者のうち、Indeed・Googleマップ・ホットペッパーなど**ネット上の公開情報だけで把握できる範囲**で「自社サイトが弱い/ない」先をリストアップして表示するだけの、シンプルな一覧ページ。

APIキーの登録・AIによるリサーチ実行など、ツールを動かすための前提は一切なし。ページを開けば、Supabaseに保存済みのデータがそのまま表示される。

## eigyo-2 / eigyo-2.5(旧版) からの変更点

- **リサーチ（一覧に載せるまで）はAIを使わない。** Indeedの求人検索やGoogle検索など、ふつうのネット閲覧で拾える情報だけで行う。ページを開くのにAPIキーは不要。
- **検索バー・使い方・デモは削除。** ページを開くと一覧が出るだけ。
- 「課題」は以前の"想定される課題"（AIが長文で生成）をやめ、クロールで確認できた事実（例: Googleビジネスプロフィールに公式サイト未登録、ポータルサイトの掲載のみ等）に基づく短い1文に変更。
- 各カードに「企業」「店舗」の種別バッジを表示（社名に株式会社・有限会社等の法人格が含まれるかで自動判定）。
- 「課題」に続けて「提案（どんな提案ができるか）」「文面（DM/メール向けの短い一文）」「台本（電話の第一声）」の3項目を追加。いずれも100〜130文字程度の軽い分量で、ボタンを押さなくても最初から表示される。AIをその場で呼び出す仕組みはなく、あらかじめ用意した内容をSupabaseに保存し、それを表示しているだけ。
- **絞り込み・並び替えツールバーを追加**。「種別（企業/店舗）」「サイト状態」で絞り込み、「新着順・五十音順・現在地から近い順」で並び替えできる。現在地からの距離は、各事業者のエリア名（例: 岡山市北区津島南）をOpenStreetMapのNominatimで大まかにジオコーディングして緯度経度を保存し、ブラウザの位置情報（`navigator.geolocation`）と直線距離（Haversine）で計算している。番地までの精度ではなく町丁目レベルの目安。
- 提案・文面・台本は初期表示を**25文字**に切り詰め、「続きを見る」（右寄せ）で全文展開。カードをより圧縮した。
- **「現状」チェックリストを追加・統一**。全カード共通で「自社サイト→Googleマップ→Instagram→Indeed」の4項目を同じ順で並べ、その後に業種固有の項目（店舗ならホットペッパー・食べログ・エキテンなど、企業ならタウンページ・ツクリンク・建設工事会社マップなど、実際に見つかった具体名）を追加。◎(良好)/○(最低限)/△(あるが弱い)/✕(なし)の4段階評価で、**全項目に必ずリンクが付く**（公式ページ等の正確なURLが分かるものはそこへ、分からないものは「事業者名＋チャネル名」でのGoogle検索へ自動でリンク）。折り畳みは全部隠さず、上位2件は常に見える状態（チラ見せ）にして、残りだけ「他n件を見る」で開閉する。カード下部にあった「情報源を見る」「Indeedで求人を見る」は、この現状リストに統合して廃止。

## 今回やったこと

Indeedで岡山市内の求人を検索 →各事業者をGoogle検索で確認し、自社の公式サイトが無い/弱い先を選定 →Supabaseの`prospects`テーブルに保存。

- **店舗（美容室・カフェ・整体・ラーメン店など）10社** — ポータルサイト・SNS掲載のみで自社サイトが無い先
- **企業（法人）8社** — 運送・製造・電気工事・産業廃棄物処理・建材・建具など。「サイト自体が無い」だけでなく、「サイトはあるがSSL非対応(http)」「無料ビルダーの初期テンプレートのまま」といった、企業ならではの"弱い"パターンも対象にした

企業は店舗に比べて自社サイトを持っている割合が高く、「完全にサイトが無い」先を探すのは店舗より難しかった。そのぶん「古い/弱いサイトのまま放置」というパターンを含めることでカバー範囲を広げている。

- データ保存先: Supabase `prospects` テーブル（eigyo-2と共通）
