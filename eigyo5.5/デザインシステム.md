# 営業AI v5.5 デザインシステム

2026-11-01、UI Pocket(https://ui-pocket.com/mobile)の公開範囲のサムネイル(みんなの銀行・SMBC等の金融/比較系アプリ)を参考に整理。ログイン必須の詳細画面までは確認していない。

## 参考にしたパターン

- 金融アプリ(みんなの銀行、三井住友銀行)の「カード型・太い数字・白背景+黒線イラストの最小配色」をベースにした
- 数字を主役にする構成(小さいラベル→太く大きい数字)を「ヒーローナンバー」として採用
- 色数を絞り、情報の強弱を濃淡(黒〜グレーの階調)だけで表現する方針は本人の指定(モノクロ/モノトーン厳守)と一致したため、そのまま踏襲

## カラートークン

既存の`:root`変数をそのまま使用。新規追加なし(アクセントカラーを増やさない方針のため)。

| 変数 | 役割 |
|---|---|
| `--bg` | ページ背景 |
| `--panel` | カード・パネルの背景(白) |
| `--panel-2` | 塊(line-group)や強調ボックスの背景(淡いグレー) |
| `--text` | 本文・最重要テキスト |
| `--muted` | 補足ラベル・キャプション |
| `--border` | 枠線 |
| `--ok` | 強調(資本金・従業員などのタグ)。アクセント色ではなく濃いグレー |

## タイポグラフィスケール

| 変数 | サイズ | 用途 |
|---|---|---|
| `--fs-xs` | 9px | 最小ラベル(hero-label、バッジ) |
| `--fs-sm` | 10.5px | カード本文(compact-line) |
| `--fs-base` | 12px | モーダル本文 |
| `--fs-md` | 13.5px | 会社名などの小見出し |
| `--fs-hero` | 16px | カードのヒーローナンバー(効果額) |
| `--fs-hero-lg` | 20px | (予約・将来の特大表示用、未使用) |

## スペーシングスケール

`--sp-1`〜`--sp-5`(4/8/12/16/24px)。既存コードは個別のpx値のまま残っている箇所が多く、今回は新規追加箇所(hero-group等)から適用を開始。全面置き換えは未実施(既存レイアウトを壊すリスクを避けたため)。

## 角丸スケール(今回、全面的に統一)

| 変数 | サイズ | 用途 |
|---|---|---|
| `--radius-xs` | 6px | バッジ、小さいタグ、ミニバー |
| `--radius-sm` | 8px | 強調ボックス(calc-alert、trust-box、num-tile、ボタン) |
| `--radius-md` | 10px | カード、パネル、line-group、conclusion-box |
| `--radius-lg` | 14px | モーダル(PC幅) |
| `--radius-xl` | 16px | モーダル(モバイル、上2角のみ) |
| `--radius-pill` | 999px | ピル型バッジ |
| `--radius-circle` | 50% | 丸ボタン・丸ドット |

それまでバラバラだった4/6/7/8/10/14/16pxの角丸を、上記7段階に統一した。

## カードの情報階層(ヒーローナンバーパターン)

カード最上部の「効果額」ブロックのみ、ラベル(`--fs-xs`・`--muted`)+太字の大きい数字(`--fs-hero`・`--text`・font-weight:800)という2階層構成にした。他の情報(予算・価格・対面)は`--fs-sm`で並列表示のまま、効果額だけを視覚的な起点にする。

## 適用範囲・やっていないこと

- 表示側(index.html)のみ変更。Googleスプレッドシート連携・計算ロジック・`gas-code.js`は未変更
- スペーシングスケールは一部(新規追加箇所)にのみ適用。既存のpx直書きは残っている(リスク回避のため全置換は見送り)
- dribbble/Mobbinは今回未調査(時間の都合でUI Pocketの公開範囲のみ参照)
